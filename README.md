# ReactProyect-TalentosTech

Este es mi proyecto final de un E-commerce creado para TalentosTech

## Instalar dependencias

Desde la raíz del proyecto, ejecuta este comando en un terminal:

```bash
npm run dev
```
## Ejecutar en modo desarrollo

Para levantar la aplicación localmente:

```bash
npm run dev
```

Luego abre en tu navegador la URL que te muestre Vite, normalmente:

```text
http://localhost:5173/
```

## Construir para producción

Para generar una versión lista para despliegue:

```bash
npm run build
```

## Vista previa de producción

Para previsualizar la build generada:

```bash
npm run preview
```

## Estructura general

- src/: componentes, contextos, estilos y páginas
- public/: recursos estáticos
- src/firebase/: configuración de Firebase
